# MVA Trainer — แอปสอนและทบทวนการดูดชิ้นเนื้อในโพรงมดลูกด้วยมือ

เว็บแอปภาษาไทยสำหรับฝึกและทบทวนหัตถการ **Manual Vacuum Aspiration (MVA)** ออกแบบให้ใช้ได้ทั้ง
**หน้างานจริง** (เปิดดูการ์ดอ้างอิงเร็วก่อนลงมือ) และ **การเตรียมสอบ** (คลังข้อสอบ เช็กลิสต์ OSCE กรณีศึกษา)

ทำงานได้แบบออฟไลน์ทั้งหมด ไม่ต้องต่ออินเทอร์เน็ต ไม่ต้องติดตั้งอะไร ไม่มีการส่งข้อมูลออกนอกเครื่อง

## เปิดใช้งาน

**วิธีที่ง่ายที่สุด** — ดับเบิลคลิกไฟล์ `index.html` เปิดในเบราว์เซอร์ได้ทันที

**แบบเสิร์ฟเวอร์** (จำเป็นถ้าต้องการให้จำความก้าวหน้าและติดตั้งลงหน้าจอมือถือได้)

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

เมื่อเปิดผ่าน http/https จะติดตั้งเป็นแอปบนหน้าจอมือถือได้ (Add to Home Screen)
และ service worker จะแคชไว้ให้เปิดใช้ได้แม้ไม่มีสัญญาณ

## มีอะไรอยู่ในแอป

|---|---|
| **บทเรียน** | 10 บท ตั้งแต่ภาพรวมและหลักฐานเชิงประจักษ์ ข้อบ่งชี้/ข้อห้าม อุปกรณ์และการเลือก cannula ยาแก้ปวดและ paracervical block ขั้นตอนหัตถการ การตรวจชิ้นเนื้อ ภาวะแทรกซ้อน การดูแลหลังทำและการคุมกำเนิด การป้องกันการติดเชื้อ จนถึงกฎหมายไทยและการให้คำปรึกษา |
| **ลำดับขั้นตอน** | เกมฝึกเรียง 14 ขั้นตอนของหัตถการให้ถูกลำดับ พร้อมตรวจคำตอบและดูเฉลย |
| **เช็กลิสต์ OSCE** | ใบประเมินทักษะ 39 ข้อ (ข้อวิกฤต 14 ข้อ) ให้คะแนน 0–2 คำนวณคะแนนและเกณฑ์ผ่านอัตโนมัติ มีช่องกรอกชื่อผู้รับการประเมิน/ผู้ประเมิน/วันที่ บันทึกประวัติ และสั่งพิมพ์เป็นเอกสารขาว-ดำใช้เก็บเข้าแฟ้มได้ |
| **คลังข้อสอบ** | 45 ข้อพร้อมคำอธิบายรายข้อ เลือกทำตามหัวข้อได้ มีโหมดฝึก (เฉลยทันที) และโหมดสอบจับเวลา 20 ข้อ พร้อมคลังข้อที่เคยตอบผิดไว้ทบทวนซ้ำ ตำแหน่งตัวเลือกที่ถูกกระจายสมดุล (12/11/11/11) เพื่อไม่ให้เดาตำแหน่งได้ |
| **กรณีศึกษา** | 6 เคสแบบตัดสินใจทีละขั้น ครอบคลุมแท้งไม่ครบ แท้งติดเชื้อ hematometra ไม่พบวิลไล การยุติการตั้งครรภ์ และครรภ์ไข่ปลาอุก |
| **แฟลชการ์ด** | 38 ใบ สำหรับท่องตัวเลขและหลักการที่ต้องจำ พร้อมจำว่าใบไหนจำได้แล้ว |
| **อ้างอิงเร็ว** | ตัวเลขที่ต้องจำ ตารางเลือกขนาด cannula ขนาดยา 4 สัญญาณว่าดูดครบ ข้อห้ามเด็ดขาด สัญญาณอันตราย และแนวทางเมื่อสงสัยมดลูกทะลุ — พิมพ์เป็นการ์ดพกได้ |

ความก้าวหน้าทั้งหมด (บทที่อ่าน คะแนนสอบ คะแนนเช็กลิสต์ แฟลชการ์ด) เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น
ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่มีการส่งข้อมูลออก

## แก้ไขหรือเพิ่มเนื้อหา

เนื้อหาทั้งหมดแยกอยู่ในโฟลเดอร์ `assets/js/data/` เป็นออบเจกต์ JavaScript ธรรมดา
แก้ได้โดยไม่ต้องแตะโค้ดส่วนอื่น และไม่ต้องคอมไพล์อะไร

เพิ่มข้อสอบหนึ่งข้อ:

```js
{ id: 46, topic: "procedure", q: "คำถาม…",
  choices: ["ตัวเลือก ก", "ตัวเลือก ข", "ตัวเลือก ค", "ตัวเลือก ง"],
  answer: 2,                       // ลำดับของตัวเลือกที่ถูก เริ่มจาก 0
  why: "คำอธิบายว่าทำไมข้อนี้ถูกและข้ออื่นผิด" }
```

ค่า `topic` ต้องตรงกับ `id` ของบทเรียนใน `lessons.js` เพื่อให้ตัวกรองหัวข้อและลิงก์จากบทเรียนทำงาน
หลังเพิ่มข้อสอบหลายข้อ ควรตรวจว่าตำแหน่งเฉลยยังกระจายสมดุล ไม่กระจุกอยู่ตัวเลือกเดียว:

```bash
node -e 'global.window={};eval(require("fs").readFileSync("assets/js/data/quiz.js","utf8"));
var d={};window.MVA.quiz.forEach(q=>d[q.answer]=(d[q.answer]||0)+1);console.log(d)'
```

เพิ่มข้อในเช็กลิสต์: ใส่ `{ id: "รหัสไม่ซ้ำ", text: "ข้อความ", critical: true, hint: "คำอธิบายเกณฑ์" }`
ลงในส่วนที่ต้องการ คะแนนเต็มและเกณฑ์ผ่านจะคำนวณใหม่ให้อัตโนมัติ

## หลังแก้เนื้อหาแล้วต้องทำอะไรอีก

แอปแคชไฟล์ไว้เพื่อให้เปิดออฟไลน์ได้ โดยใช้กลยุทธ์ *stale-while-revalidate* — ผู้ใช้จะเห็นเนื้อหาใหม่
ในการเปิดครั้งถัดไปหลังจากที่เครื่องดึงไฟล์ใหม่มาเก็บแล้ว หากต้องการให้เปลี่ยนทันทีในการเปิดครั้งเดียว
ให้เพิ่มเลขเวอร์ชันของแคชใน `sw.js` (บรรทัด `var CACHE = "mva-trainer-v2";`) ทุกครั้งที่แก้เนื้อหาสำคัญ

## สิ่งที่ตรวจสอบแล้ว

ทดสอบด้วยเบราว์เซอร์จริง (headless Chromium ผ่าน DevTools Protocol) ครอบคลุม

- ทุกหน้าเรนเดอร์ได้และไม่มีข้อผิดพลาดใน console รวมถึงหน้าที่ระบุรหัสบทเรียน/เคสที่ไม่มีอยู่จริง
- ทำข้อสอบครบทั้งสองโหมดจนถึงหน้าเฉลย ตัวจับเวลาเดินจริงและไม่ค้างข้ามชุด
- เช็กลิสต์: ให้คะแนนครบได้ 78/78 = 100% ตัดสินผ่าน/ไม่ผ่านถูกต้อง และหน้าไม่เด้งกลับด้านบนขณะให้คะแนน
- เดินกรณีศึกษาจนถึงหน้าสรุป และเล่นซ้ำได้
- ปิดอินเทอร์เน็ตแล้วยังเปิดใช้งานได้ครบ (service worker แคชไฟล์ 13 รายการ)
- ไม่มีการล้นแนวนอนที่ความกว้างหน้าจอ 390px
- ความคมชัดของสีผ่านเกณฑ์ WCAG AA (อัตราส่วน ≥ 4.5:1) ทั้งโหมดสว่างและโหมดมืด
- หน้าพิมพ์บังคับเป็นขาว-ดำเสมอ แม้ผู้ใช้กำลังเปิดโหมดมืดอยู่

## ข้อจำกัดความรับผิดชอบ

เนื้อหาในแอปนี้จัดทำเพื่อการศึกษาและทบทวนของบุคลากรทางการแพทย์เท่านั้น ไม่ใช่คำสั่งการรักษาสำหรับผู้ป่วยรายบุคคล
ก่อนนำไปปฏิบัติให้ตรวจสอบกับแนวปฏิบัติล่าสุดขององค์การอนามัยโลก ราชวิทยาลัยสูตินรีแพทย์แห่งประเทศไทย
ประกาศกระทรวงสาธารณสุข ข้อบังคับแพทยสภา และระเบียบของหน่วยงานท่านเสมอ
ขนาดยาและตัวเลขทุกค่าต้องทวนกับเอกสารกำกับยาและแนวทางของสถานพยาบาลก่อนใช้จริง
เนื้อหาส่วนกฎหมายอ้างอิงประมวลกฎหมายอาญาฉบับแก้ไข พ.ศ. 2564 ซึ่งอาจมีการแก้ไขเพิ่มเติมภายหลัง

มีอย่างน้อยหนึ่งประเด็นที่แนวทางสากลกับแนวปฏิบัติในไทยยังไม่ตรงกัน คือการให้ **anti-D immunoglobulin**
ก่อนอายุครรภ์ 12 สัปดาห์ ซึ่งแนวทางองค์การอนามัยโลก พ.ศ. 2565 ระบุว่าไม่จำเป็น แต่หลายหน่วยงานในไทยยังให้อยู่
แอปได้ทำหมายเหตุกำกับไว้ในบทเรียนและคำอธิบายข้อสอบแล้ว ในการทำงานให้ยึดระเบียบของหน่วยงานท่าน
และในการสอบให้ตอบตามแนวทางที่หลักสูตรของท่านใช้
