# แอปสอนหัตถการ: การใส่ห่วงอนามัย (IUD)

เว็บแอปสำหรับ **นักศึกษาแพทย์** ใช้ทบทวนและฝึกหัตถการการใส่ห่วงอนามัยบนมือถือ
ออกแบบมาให้เปิดจากโทรศัพท์ ติดตั้งลงหน้าจอโฮมได้เหมือนแอป และ **ใช้งานต่อได้แม้ไม่มีอินเทอร์เน็ต**

---

## เนื้อหาในแอป

| แท็บ | สิ่งที่อยู่ข้างใน |
|---|---|
| 📚 **เรียนรู้** | ชนิดของห่วงและการเปรียบเทียบ, จังหวะเวลาที่ใส่ได้, ข้อห้ามตาม WHO MEC, การประเมินผู้รับบริการ, การเตรียมเครื่องมือ |
| 🩺 **หัตถการ** | 12 ขั้นตอนเรียงตามลำดับจริง แบ่งเป็น 4 ระยะ แต่ละขั้นบอก *สิ่งที่ต้องทำ / ทำไมต้องทำแบบนี้ / จุดที่มักพลาด* พร้อมภาพประกอบ และติ๊กความคืบหน้าได้ |
| ⚠️ **ปัญหา** | อาการเตือน PAINS และการจัดการปัญหาระหว่างทำกับภาวะแทรกซ้อน 7 หัวข้อ |
| ✅ **ประเมิน** | แบบประเมินทักษะ 26 ข้อ ให้คะแนน 0–2 แบบ DOPS พร้อมเกณฑ์ผ่าน และข้อ critical ที่พลาดไม่ได้ |
| 🧠 **ควิซ** | ข้อสอบ 14 ข้อ สลับลำดับทุกครั้ง มีคำอธิบายเฉลยทุกข้อ และเก็บสถิติคะแนนสูงสุด |

ภาพประกอบเป็นแผนภาพ SVG ที่วาดในแอปโดยตรง จึงคมทุกขนาดหน้าจอและใช้ได้เมื่อออฟไลน์:
ทิศทางมดลูกคว่ำหน้า–คว่ำหลัง, ตำแหน่งหนีบ tenaculum, การวัดความลึกโพรงมดลูก,
การตั้ง blue flange และลำดับ 3 จังหวะของ withdrawal technique

**ลิงก์สำหรับนักศึกษา:** `https://noyk12115-del.github.io/Mva/iud/`

ขอแค่มีอินเทอร์เน็ตตอนเปิดครั้งแรกเท่านั้น

ข้อความที่ส่งให้นักศึกษาได้เลย

> แอปทบทวนหัตถการใส่ห่วงอนามัย เปิดลิงก์นี้ในมือถือได้เลย ไม่ต้องสมัครหรือโหลดอะไร
> https://noyk12115-del.github.io/Mva/iud/
> เปิดครั้งแรกให้ต่อเน็ตไว้ หลังจากนั้นเปิดซ้ำได้แม้ไม่มีสัญญาณ

หลังเปิดครั้งแรกแล้ว ไฟล์จะถูกเก็บไว้ในเครื่องเอง เปิดซ้ำได้แม้ไม่มีสัญญาณโดยที่นักศึกษา
ไม่ต้องทำอะไรเพิ่ม และถ้าใครอยากให้อยู่หน้าจอโฮมเหมือนแอปจริงก็กดเพิ่มเองได้
(iPhone: ปุ่มแชร์ใน Safari → *เพิ่มไปยังหน้าจอโฮม* / Android: เมนู ⋮ → *ติดตั้งแอป*)
แต่ไม่จำเป็นต้องทำ ใช้จากลิงก์ตรง ๆ ได้เลย

ความคืบหน้าขั้นตอน ผลประเมิน และคะแนนควิซถูกเก็บไว้ใน `localStorage`
ของเครื่องนักศึกษาเท่านั้น ไม่ส่งกลับมาที่อาจารย์ และไม่มีการเก็บข้อมูลผู้ป่วย

## การนำขึ้นใช้งาน

เป็นเว็บแบบ static ล้วน ไม่ต้อง build และไม่มี dependency

ลิงก์ข้างต้นเผยแพร่อัตโนมัติด้วยเวิร์กโฟลว์ `.github/workflows/deploy-pages.yml` ที่ราก repo
ทุกครั้งที่ push ขึ้น default branch โดยแอปนี้อยู่ในโฟลเดอร์ `iud/` จึงได้ URL ลงท้ายด้วย `/iud/`
และไม่ทับกับแอป MVA ที่อยู่ที่ราก

**ทดสอบในเครื่อง**

```bash
python3 -m http.server 8099
# เปิด http://localhost:8099/iud/
```

> ต้องเปิดผ่าน HTTP server ไม่ใช่ `file://` เพราะ service worker ต้องการ origin จริง

## โครงสร้างไฟล์

```
index.html                 โครงหน้าและแท็บ
manifest.webmanifest       ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                      service worker (cache-first)
assets/css/style.css       ธีมสว่าง/มืด, มือถือเป็นหลัก
assets/js/content.js       เนื้อหาทางการแพทย์ทั้งหมด — แก้ที่ไฟล์นี้ไฟล์เดียว
assets/js/diagrams.js      ภาพประกอบ SVG
assets/js/app.js           การแสดงผลและการเก็บความคืบหน้า
assets/img/                ไอคอนแอป
```

### การแก้ไขเนื้อหา

เนื้อหาแยกออกจากโค้ดทั้งหมดใน `assets/js/content.js`:

* `CONTENT.learn` — หัวข้อในแท็บเรียนรู้ (รองรับบล็อกชนิด `table`, `list`, `callout`, `checklist`)
* `CONTENT.steps` — ขั้นตอนหัตถการ (`do`, `why`, `pitfall`, `diagram`)
* `CONTENT.troubles` — ภาวะแทรกซ้อน
* `CONTENT.rubric` — แบบประเมินทักษะ ตั้ง `critical: true` เพื่อทำให้เป็นข้อที่พลาดไม่ได้
* `CONTENT.quiz` — ข้อสอบ (`a` คือดัชนีของตัวเลือกที่ถูก เริ่มจาก 0)

เพิ่มข้อสอบหรือขั้นตอนใหม่ได้โดยไม่ต้องแตะ `app.js`
หากเพิ่มไฟล์ใหม่ ให้เพิ่มชื่อไฟล์ในรายการ `ASSETS` ของ `sw.js` และเปลี่ยนเลขเวอร์ชันของ `CACHE` ด้วย
